# A Needle in the Haystack

</div>

<div align = "center">

<h3>Can you find the needle in the haystack?</h3>

<br>

<h3>Write a function <em>findNeedle()</em> that takes an <em>array</em> full of junk but containing one <em>"needle"</em></h3>

<br>

<h3>After your function finds the needle it should return a message (as a string) that says:</h3>

<br>

<h3><em>"found the needle at position "</em> plus the <em>index</em> it found the needle, so:</h3>

<br>

<h3>Example 1:</h3>

<pre>findNeedle( ["hay", "junk", "hay", "hay", "moreJunk", "needle", "randomJunk"] )</pre>

<p>The function will return the string: &nbsp;<em><strong>"found the needle at position 5"</strong></em></p>

<h3>Example 2:</h3>

<pre>findNeedle( ['3', '123124234', undefined, 'needle', 'world', 'hay', 2, '3', true, false] )</pre>

<p>The function will return the string: &nbsp;<em><strong>'found the needle at position 3'</strong></em></p>
